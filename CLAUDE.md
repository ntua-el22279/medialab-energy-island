# CLAUDE.md

Project: **MediaLab Energy Island**, the final project for NTUA Multimedia Technology (JavaFX).

## Rules for every session
- **Log everything in `WORKLOG.md`.** After any work (files created or changed, decisions, setup steps, problems), append a dated entry under `## Log` and update the *Workspace layout*, *Environment* and *Open items* sections when they change.
- Reference material lives in `docs/course-material/`: the brief PDF and the scenario guide `ΟΔΗΓΟΣ_ΣΕΝΑΡΙΩΝ.md`. The scenario file format is **binding**.
- All application data must live under `medialab/`. Scenarios are in `medialab/scenarios/<id>/` and saved plans/results go in `medialab/results/`. Do not modify the sample scenarios `a` and `b`.
- Allowed libraries: Java standard library, JavaFX, and **one** JSON library. Nothing else.
